# CatQuest

**CatQuest** is an educational web development project created to help cat lovers and owners learn about different cat breeds. The platform organizes information regarding history, physical traits, temperament, and care requirements into an accessible, flat HTML/CSS format.

---

## Features

- **Chessboard Directory:** Main navigation page featuring a grid of cat breeds (`breeds.html`).
- **Breed-Specific Video & Media:** Individual detail pages for 15 cat breeds with dedicated media elements.
- **Project & Resource Hub:** Site information, attribution, and custom visual elements (`about.html`).
- **Pure HTML & CSS:** Structured cleanly without external scripts or dynamic libraries.

---

## Tech Stack

- **HTML5:** 18 pages total (`index.html`, `breeds.html`, `about.html`, and 15 individual breed pages).
- **CSS3:** 3 dedicated stylesheets (`index.css`, `breeds.css`, `about.css`).

---

## Directory Structure

All project files, media assets, and stylesheets reside in a flat single-folder structure:

```text
CatQuest/

├── breeds.html         # Main page featuring the breed chessboard
├── about.html          # Information and resources about the website
